# EventFlow

### Intelligent Capacity & Crowd Management for Mega-Events

EventFlow is a smart event-management platform designed to help cities and organizers manage **accommodation, transportation, event schedules, visitor demand, and crowd movement** during large-scale events.

## 🚀 Live Demo

**[EventFlow](https://event-flow-ttol-five.vercel.app/)**

## 🎯 Problem

Mega-events can attract thousands or millions of visitors within a short period, creating pressure on:

* Hotels and accommodation
* Public and private transportation
* Event venues
* Crowd movement
* City infrastructure
* Emergency and resource management

EventFlow provides a centralized platform to help organizers understand demand and coordinate resources efficiently.

## ✨ Key Features

* 🏨 **Accommodation Management** — Monitor hotel capacity and availability.
* 🚌 **Transportation Management** — Track transportation requirements and movement.
* 📅 **Event Scheduling** — Manage events, venues, and schedules.
* 👥 **Crowd Management** — Visualize visitor demand and crowd movement.
* 📊 **Analytics Dashboard** — View important event and capacity information.
* 📍 **Location-Based Insights** — Connect demand with different locations.
* ⚡ **Real-Time Planning** — Support faster decisions during large events.

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
* **Version Control:** Git + GitHub

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/kanojiya-ashish/EventFlow.git
cd EventFlow
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:8443
```

### 4. Create production build

```bash
npm run build
```

The production files will be generated inside:

```text
dist/
```

## 📦 Deployment

The project can be deployed directly through **Vercel** by connecting the GitHub repository.

Recommended Vercel settings:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
Install Command: npm install
```

Vercel automatically creates a new deployment when changes are pushed to the connected Git repository.
